# Nithin Sai Gudduru — Portfolio

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the two `Add live project URL` links in `index.html` with your real project URLs.
2. Replace the LinkedIn and GitHub placeholder URLs with your actual profiles.
3. Optionally add a `resume.pdf` file to `assets/` and a Resume button.
4. Publish the folder using GitHub Pages, Netlify, or Vercel.

## Included
- Responsive single-page portfolio
- Your uploaded profile photo
- Projects, skills, education, certifications and achievements
- Certificate links
- Mobile navigation
- Scroll reveal animations
